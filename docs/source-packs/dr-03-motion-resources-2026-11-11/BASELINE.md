## Znaczenie etykiet nowości
**NEW** = konkretna pozycja lub metoda nieobecna w odczytanym baseline katalogu i relewantnych reference cards, nie dowód nieistnienia kiedykolwiek w całej historii FrameCore. **KNOWN_NEW_CAPABILITY** = źródło/obszar znany, ale wskazana delta. **ALREADY_COVERED** = ten sam cel już obsługiwany; ewentualnie reference comparator. **DUPLICATE/FORK** = pochodny wariant bez wykazanej nowej użyteczności. **BASELINE_UNKNOWN** = nie można rozstrzygnąć przez brak konkretnego baseline. FrameMotion samo pozostaje Unknown niezależnie od etykiety względem Studio/Toolbox/Open Assets.
