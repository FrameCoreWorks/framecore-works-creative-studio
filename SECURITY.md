# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.
Use GitHub's private report: open the **Security** tab of this
repository and choose **Report a vulnerability**.

If that button is missing, open an issue that says only
"security contact needed" (no details), and the maintainer
will reply with a private channel.

## Scope

This repository holds plugin instructions, scripts and
documentation. Reports about hooks, installers, scripts that
write outside the project, unpinned downloads or leaked
secrets are in scope.

## Supported versions

Only the latest release on `main` is supported.
