# Creative Studio 1.85.0

- **See how a web animation is built.** Point Studio at a page and it measures the motion (library, durations, delays, easing, scroll ranges) to rebuild the effect in your own film, without copying the site.
- **Recommended extensions.** A curated list of outside tools you can add to Codex or Claude Code with their own installers, starting with REA for software reverse engineering. Nothing is installed unless you ask.

The welcome, menus and the 37 skill IDs are unchanged. See [verification](VERIFICATION.md) and [release status](RELEASE_STATUS.md).
