# Creative Studio 1.40.1

A fix for 1.40.0: the Motion Graphics Workflow could fail to load.

- **The motion skill loads again.** In 1.40.0 one punctuation mark in the skill's description made its header unreadable for a strict host. It is fixed, and Studio's checks now catch this kind of error before a release.
- **Everything from 1.40.0 stays.** A video request still gets the choice between generator prompts and a finished MP4 from code, with sound designed here.

Startup, the welcome, menus and all 37 skill IDs are unchanged. See [verification](VERIFICATION.md) and [release status](RELEASE_STATUS.md).
