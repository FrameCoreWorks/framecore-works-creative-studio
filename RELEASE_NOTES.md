# Creative Studio 1.48.0

Studio in Claude, and one tool list for every host.

- **Install in Claude.** Studio is now a Claude plugin: in Claude Code add the marketplace `FrameCoreWorks/framecore-works-creative-studio` and install `framecore-work-creative-studio`; in the Claude apps add it under Customize > Plugins. See the [Claude installation guide](CLAUDE_INSTALL.md).
- **Know what works where.** One list says, for ordinary ChatGPT, ChatGPT Work, Codex, Claude Code and the Claude apps, which tools Studio uses there, which were seen working, which you install yourself and which that host cannot run. The environment check shows it for the host you are in.

Startup, the welcome, menus and all 37 skill IDs are unchanged. See [verification](VERIFICATION.md) and [release status](RELEASE_STATUS.md).
