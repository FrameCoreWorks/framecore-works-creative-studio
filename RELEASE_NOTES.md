# Creative Studio 1.45.0

Studio checks its own tools.

- **One check for everything.** Ask Studio what is installed and it checks Python, FFmpeg, Node.js, Chrome, Remotion, HyperFrames and the libraries its tools use, says which kinds of work are ready, what is missing or out of date, and gives the install commands for your system.
- **Right after installation.** The installation guides for Codex and ChatGPT Work now run this check once and show you the result.
- **Nothing installed behind your back.** The check only reads. Studio installs a tool only when you ask, and HyperFrames stays an optional engine you choose.

Startup, the welcome, menus and all 37 skill IDs are unchanged. See [verification](VERIFICATION.md) and [release status](RELEASE_STATUS.md).
