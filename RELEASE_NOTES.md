# Creative Studio 1.44.0

HyperFrames as an engine for motion graphics, where it can run.

- **More power for code-made videos.** In Codex or a local project with Node.js, FFmpeg and Chrome, Studio can now offer HyperFrames, HeyGen's open video framework, for launch films built from a website, longer narrated videos, word-level captions and music-driven edits. Studio still plans the video with you, keeps your approvals and copy, and reviews the result.
- **Installed only when you ask.** HyperFrames is installed with a fixed version through its own plugin or skills command, never bundled into Studio. In ChatGPT, the bundled renderer and the motion player stay the route.
- **HeyGen media only on request.** HeyGen's catalog of music, effects, voices and avatars is used only if you ask for it and have a HeyGen account.

Startup, the welcome, menus and all 37 skill IDs are unchanged. No HyperFrames render has been run through Studio yet. See [verification](VERIFICATION.md) and [release status](RELEASE_STATUS.md).
