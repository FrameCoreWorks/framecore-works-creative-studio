# Creative Studio 1.75.0

Fixes from a broad test of every skill and tool.

- **The right skill does the work.** When you ask a skill for something outside its job (an animated banner from the poster skill, new copy from the polishing skill), it hands the task to the skill that owns it.
- **Nothing invented.** Studio no longer claims typographic fixes it did not make or adds health claims to product copy, and it never stores consent to pay.
- **Fewer questions at once.** With little to go on, Studio asks one question and fills in the rest with labelled defaults.
- **Clearer tool errors.** A missing or wrong file now gives one clear message, and finished files are never overwritten.

The welcome, menus and all 37 skill IDs are unchanged. See [verification](VERIFICATION.md) and [release status](RELEASE_STATUS.md).
