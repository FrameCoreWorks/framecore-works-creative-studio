# Creative Studio 1.49.0

Every tool Studio needs, checked when you install it.

- **One list, all required.** Python with its image, sound, SVG, font and animation libraries, FFmpeg, Node.js, Chrome, the Remotion, GSAP, 3D and motion-toolkit starters, and HyperFrames.
- **A final check ends the installation.** In Codex and Claude Code the installation is complete only when every tool is in place; the check shows what is missing and the exact commands for your system. In ChatGPT and the Claude apps it shows what that chat can and cannot run.
- **Nothing is installed behind your back.** You run the commands, or ask the assistant to; the check only looks.

Startup, the welcome, menus and all 37 skill IDs are unchanged. See [verification](VERIFICATION.md) and [release status](RELEASE_STATUS.md).
