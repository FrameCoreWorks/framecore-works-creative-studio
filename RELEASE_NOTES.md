Openverse is removed from active routing without deleting package paths. Startup content, vendor snapshots and private hosted integration overlays are preserved. Actual Work download, full decode, Earshot light measurements and Studio manifest validation passed. Codex/Claude active-client behavior, neural listening and a post-update new-conversation startup were not run.
