# Creative Studio 1.81.0

Fixes from a technical audit.

- **Approvals you can trust.** New captions need a new approval, exact copy must really appear as written, and a video longer than planned is caught.
- **Exports that keep the whole film.** A short voice-over no longer cuts the animation, and changing a scene's length keeps the captions in step.
- **No dead ends.** Where Studio cannot run code, it gives you the contract and the player link right away.

The welcome, menus and all 37 skill IDs are unchanged. See [verification](VERIFICATION.md) and [release status](RELEASE_STATUS.md).
