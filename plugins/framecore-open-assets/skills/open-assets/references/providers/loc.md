# Library of Congress — Gottlieb photographs

Sources: [JSON/YAML API](https://www.loc.gov/apis/json-and-yaml/), [request limits](https://www.loc.gov/apis/json-and-yaml/working-within-limits/), [general legal/client rules](https://www.loc.gov/legal/), [official API tutorial and Gottlieb collection description](https://guides.loc.gov/digital-scholarship/tutorials), [Gottlieb rights](https://www.loc.gov/collections/jazz-photography-of-william-p-gottlieb/about-this-collection/rights-and-access/), [official dedication account](https://www.loc.gov/loc/lcib/0606/gottlieb.html). Read 2026-10-28. Legal page and tutorial were readable; collection rights HTML was denied, so the module requires the exact positive dedication in official item JSON as well as collection scope.

No account/key is needed. This adapter is restricted to the Gottlieb collection's photographs with the explicit public-domain dedication. The collection also contains newspaper clippings used by permission: those are excluded. A phrase merely containing “public domain” is insufficient; negated or contradictory rights are refused. Broad LoC “no known restrictions” is not an accepted licence. Privacy/publicity and intended-use checks remain separate. Preserve item page, creator, dedication text and collection rights link; do not relabel the dedication as CC0/PDM.

The general legal policy recommends at most 10 requests/minute, stricter than the JSON API's 20/minute ceiling. Use serial pacing of 6.1 seconds between completed requests and the next request, honest UA, provider cache headers, bounded results and no bulk job. Stop on 403/429. Search the collection, resolve each selected photograph's item JSON, then use its JPEG renditions (small through large). Only allowlisted official media hosts are permitted. TIFF/JP2/audio/video are not implemented by this module.

Work 2026-10-28: a broad jazz query exposed clippings and correctly delivered nothing. A portrait query, explicit item dedication and actual JPEG download/decoding passed. This is not blanket qualification of all LoC collections.
