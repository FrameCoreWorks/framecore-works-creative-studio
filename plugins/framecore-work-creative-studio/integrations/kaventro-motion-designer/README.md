# kaventro/motion-designer attribution

This directory records a partial method adaptation from [kaventro/motion-designer](https://github.com/kaventro/motion-designer), an MIT-licensed agent skill that makes launch films and short videos from code. The exact source commit, reviewed files and hashes are in [source-manifest.json](source-manifest.json).

[LICENSE](LICENSE) is the unchanged upstream notice. Two upstream scripts are retained unchanged in the [motion sync assets](../../skills/hyperframes-workflow/assets/motion-sync/README.md): `beats.py` and `music_edit.py`. The style values, motion vocabulary, review passes and sound brief are rewritten for Studio; see the [adaptation map](../../skills/hyperframes-workflow/references/kaventro-motion-designer-adaptation.md).

No upstream skill, template, command, music or voice model, or installer is installed or executed.
