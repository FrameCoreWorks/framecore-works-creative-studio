# Creative Studio 1.0 scope

This is the 1.0.0 package. GitHub distribution and a hosted ChatGPT update are separate publication operations.

## Included

The established Studio workflow covers brief interpretation, researched creative direction, concise ideation, collaborative development, product and character references, static graphic design, story and dialogue, shot continuity, storyboard/reference sheets, image/video prompts, audio and editing plans, scoped critique and delivery handoffs.

There are 37 canonical skill entrypoints. The compatibility name `producer-ai-task-builder` forwards to Audio Production Director; it is not a separate music provider. The original pinned Static Graphic Design Creator and Workflow Kit bundles remain intact. The author's uploaded logo is used as the plugin logo and composer icon.

## Execution boundary

The plugin contains instructions, references, templates and bounded local helpers. It uses only available, authorized tools. Without a renderer, audio engine or editor, it can prepare a useful production specification but cannot claim to have generated, heard, rendered or inspected absent media.

Provider accounts, costs and capabilities belong to the active environment. No paid API key, automatic media upload, persistent project database or cross-environment memory synchronization is bundled. Handoffs preserve context through explicit records. Third-party Custom GPT migration is limited to the source material actually available; this version does not claim every historical custom was fully migrated.

## Verification boundary

The release preparation runs structural checks and verifies preservation against dev.33. Historical Node, Python and fresh text-use results keep their original scope. The 167 evaluation specifications are unexecuted plans. Real-client pilots, paid generation and exhaustive host tests are not required or performed in this preparation.

The repository wrapper includes the marketplace, installation/update guides and packaging helper. A GitHub commit or ZIP does not update an existing hosted plugin automatically. Installation and refresh must use an actual supported host mechanism. Public directory availability and universal web/mobile import remain unverified.
