## Authority decisions

Pipeline Core now governs shared artifact/state/handoff contracts, the bounded Loop Protocol and source-to-request prompt binding. Copy Voice owns ready-to-use copy and Humanizer remains its voice-review support. Creative Video Producer coordinates end-to-end video; Caption Studio, OpenCut, Remotion and HyperFrames own their scoped production routes. Reference Pack Curator and Asset Manifest add explicit source authority and version traceability. Hipson Adapter adds bounded instruction/research packets. Existing deep domain knowledge stays connected through the same route.

Studio’s stronger decisions govern conditional, trigger-based creative research, Quick-first short ideas, one targeted clarification after rejection, complete Static Graphic Design Creator, Audio Production Director naming, observed host capabilities, required continuity versus execution readiness, and user-scoped profile persistence. Repository onboarding-preference-tuning merges into studio-workstyle-profile; storyboard-director merges into storyboard-sequence-architect; producer-ai-task-builder merges into audio-production-director. No second active catalog, onboarding sequence or music owner is introduced.

Upstream installation instructions describe separate native/project-local installations. They are retained as source material only. The plugin does not automatically execute the installer, install permanent agents, connect providers, run embeddings, upload private material, schedule a review or synchronize hosts. Local recovery/index utilities are available as optional source tools when the host exposes execution and the user requests the operation. Their actual scope and limitations are in the active project-recovery guide.
