# Audio arrangement, VO performance and mix workbook

Read this for an arrangement decision, a directed VO take or a concrete audio complaint. It supplements the [evidence and handoff contract](audio-evidence-and-av-handoff.md). These are original planning exercises, not tested renders, measured recordings or a new audio engine. Use the requested subset. A standalone audio review needs findings and a useful next test; it does not need a song task packet.

## 1. Choose the level at which the problem lives

| Level | Decision | Useful evidence | Typical wrong intervention |
|---|---|---|---|
| Composition / wording | Which musical or verbal idea matters? | Authorized lyrics, approved script, intended listener effect | Trying to repair an unclear message by adding brightness |
| Arrangement | Which part occupies this moment, register and role? | Actual passage, stems if available, or labelled proposed form | Adding another lead to make a crowded passage clearer |
| Performance | What is the voice/player doing for the listener? | Audible take or targeted user description | Treating an unconvincing intention as a loudness defect |
| Capture / source | Is the usable sound present? | Source recording and documented inspection | Assuming processing can restore missing or damaged content |
| Mix / edit | How do valid elements coexist and connect? | Actual relevant range, preferably before/after or available stems | Prescribing a processor chain from a filename |
| Delivery | Does the actual file meet the requested destination? | Destination specification and actual measured/exported file | Treating a loudness target as proof of intelligibility |

This is a decision ladder, not a required six-stage job. Start at the user's entry point. If only a stereo mix exists, do not promise isolated changes to an unavailable stem. A reconstruction or new generation is a different operation from editing that mix.

## 2. Arrangement by responsibility

Write the job of each active part before increasing density. Useful responsibilities include pulse, low foundation, harmonic information, lead idea, response, texture, transition and silence. One instrument may change job; several may intentionally share one. Separate louder, busier, higher, wider and emotionally more exposed: they are different changes.

For each proposed section ask:

1. What should the listener follow here?
2. Which part supplies that information, and which parts leave space for it?
3. What is retained from the previous section so the piece still feels connected?
4. What changes at the boundary, and what should that change make perceptible?
5. Is the ending a resolution, interruption, sustain or practical edit point?

Do not assume a universal bar count, drop, bridge or chorus lift. When no audio is inspected, a section map is proposed composition, not analysis. Repetition can preserve the idea while a single responsibility moves between parts.

### Worked example A — original instrumental for a repair workshop film

**Hypothetical supplied brief:** an original 45-second instrumental for a small workshop film; patient handwork, no voices, no triumphant reveal. The user requests a 45-second deliverable. No track, generator or verified timing exists. The following intervals are an editorial proposal totaling 45 seconds, not measured audio or deterministic model controls.

**Creative decision:** a restrained wooden pulse provides continuity; a short rounded keyboard figure supplies recognition. The piece opens space when the visual demonstration needs attention, then returns without a final impact.

| Proposed interval | Listener priority | Arrangement decision | Boundary intention |
|---|---|---|---|
| 0–9 s | Learn the small repeating figure | Soft keyboard figure with space between statements; no percussion initially | Introduce pulse gently near the next phase |
| 9–23 s | Feel steady work | Dry wooden pulse and sparse low notes support the same figure | Retain pulse into the sparse phase |
| 23–34 s | Leave attention for precise hand action | Remove the keyboard figure; keep pulse with occasional low support | Figure can return without a riser |
| 34–45 s | Recognize completion without a victory cue | Return the original figure; gradually leave only its final natural decay | Clean ending, no new phrase cut off |

**Complete generator-neutral music prompt:**

```text
Create an original instrumental for a quiet workshop film. The requested edit length is 45 seconds; treat the timing outline as a target to review against the actual result. Make patient repetition and careful handwork the central feeling. Use a short, rounded keyboard figure as the identifying idea, a dry wooden pulse for continuity and sparse low notes for support. Keep the spaces between events audible.

Begin with the keyboard figure alone. Introduce the pulse gradually for the working passage. In the later middle passage, withdraw the keyboard figure so the pulse can support detailed visual attention without another melodic lead. Return the same figure for the ending, then let it decay naturally. Maintain restrained energy throughout; the final return should feel familiar rather than triumphant. Avoid voices, choir or word-like vocal texture, a dramatic riser and a final impact. Preserve clear separation between the pulse and the low notes.
```

**Review:** check whether the identifying figure remains recognizable, the intended sparse passage actually offers less competing information, no vocal material appears, and the ending completes its phrase. Actual duration, section boundaries, loudness and export format remain `Unknown` until verified. If it runs long, first decide whether a verified edit operation can preserve the accepted phrase; do not silently label it 45 seconds.

**One-variable repair:** if the middle still feels busy, preserve the pulse, low pattern, tempo feel and opening figure. Remove only the additional middle melodic responses. Compare that passage with the previous revision; do not simultaneously change instrumentation, genre and ending. This brief does not authorize a paid generation.

## 3. VO direction that can be performed

An effective performance note identifies the addressee, the speaker's immediate intention, a thought or emphasis change, and the ending. Prefer a playable instruction such as “give the listener room to decide after the first sentence” over a stack of emotional adjectives. Keep written words separate from delivery notes so stage directions cannot become spoken output.

For a recorded voice, distinguish a performance problem from a capture problem. A retake may address unclear articulation or a misplaced emphasis; a capture comparison can test room, position or plosives. Use the actual microphone context if supplied. Do not prescribe one distance, EQ frequency or compression setting for every voice. For synthetic VO, performance descriptions are intentions; supported voice controls require current documentation of the selected surface.

### Worked example B — approved Polish VO under a short demonstration

**Hypothetical supplied brief:** approved short editorial VO, one adult fictional voice, quiet invitation, requested slot 12 seconds. Humanizer has already approved the wording. This is a performance plan; no take has been heard, and natural read duration is `Unknown`.

**Locked words:**

```text
Nie musisz robić wszystkiego od nowa. Zobacz, co możesz zachować, i zacznij od jednej rzeczy.
```

**Complete performance brief:**

```text
Read only the approved Polish text, without adding words. Speak to one person who is hesitating before a small practical task. Give the first sentence as reassurance, without sounding like a sales announcement. Let a natural thought pause separate it from the invitation. Give a little additional attention to “zachować”; keep “jednej rzeczy” simple and settled. Use clear everyday articulation and an unforced voice. Keep a consistent acoustic perspective throughout the take. Do not whisper or stretch every word to fill the slot.

The requested slot is 12 seconds. Record or produce a natural read, then verify the actual duration. If the exact text cannot fit comfortably, report the mismatch; preserve the wording while considering more picture time or a separately approved copy revision.
```

**Audio handoff:** VO leads attention. Any music keeps its identifying texture but leaves the spoken invitation clear; add no new melodic response during those words. A single tabletop contact effect belongs to its visible contact, not to a guessed syllable. Picture and exact effect placement go to the video owner. Caption source is the approved script until compared with an actual take; it is not a verified transcript or timed SRT.

**Smallest useful tests:** compare the take with the exact words; check whether the change of thought can be heard without artificial pauses; measure duration only through an available actual method. If words are clear alone but lost with music, test the music relationship before changing the accepted voice. Do not infer clarity from a transcript alone.

## 4. Audio repair tree

First identify the evidence state. If no listening or suitable analysis is available, work from the user's report and label each cause a hypothesis. When inspection is available, record the actual scope and method; a full-file scan and a listen to one range support different findings.

| Branch / discriminating question | Next bounded test | If the test supports it |
|---|---|---|
| Are the words wrong, missing or in the wrong language? | Compare audible take with approved words over the affected phrase | Repair text adherence or take; preserve unrelated mix decisions |
| Is the voice unclear on its own? | If the source/voice stem exists, compare that passage in isolation | Investigate performance/capture/source before competing layers |
| Is the voice clear alone and unclear in context? | Compare the same passage with the competing layer reduced or absent | Adjust that relationship or arrangement; avoid a whole-song preset |
| Is there a click or abrupt change at an edit? | Inspect/listen around both sides of the boundary; check source continuity | Adjust that local edit while preserving words and musical attack |
| Does the issue occur only on one playback route? | Compare actual routes at a comfortable comparable level; record the routes | Investigate that interaction before assuming a source-wide defect |
| Does apparent harshness coincide with peaks? | Compare listening evidence with actual peak/clip analysis if available | Name what was measured; distinguish overload from a subjective timbre |
| Is “too quiet” a destination complaint? | Obtain the requested delivery specification and measure the actual file with an appropriate method | Resolve that specification; do not invent a web-wide loudness target |
| Is the sound detached from a visible action? | Pass the actual combined interval to video for audiovisual alignment | Preserve a deliberate authored offset, otherwise repair the causal relation |

Do not use this table to claim a cause has been established. Some symptoms have several causes; choose the cheapest discriminating test within actual capability and authorization. Avoid another upload or paid run merely to complete a checklist.

### Worked example C — review from a user's report only

**Input:** “The first sentence is clear, but the last word of the second sentence disappears when the music comes back.” No media or stems are supplied.

**Useful standalone response:**

> Evidence: `user_report_only`. You report a loss of the final word when the music returns; I have not heard the mix. A competing musical entrance is one plausible cause, but the take itself may also be unclear. First compare that exact phrase with the music muted, if your project lets you do that. If the word becomes clear, keep the approved take and test a later or quieter return of the same music. If it stays unclear, check the voice source before changing the bed. Success means the final word is understandable in context while the accepted musical entrance still feels intentional.

**Conditional complete repair note for the first branch:** preserve approved text, selected voice take, music identity and all other cue placements. Change only the music's return around the affected final word, using the actual take as timing authority. Compare the original and revised passage, including the preceding breath and following music. Do not supply an invented timecode, measured LUFS, or assurance that masking has been diagnosed. The user requested review, so no full production packet is necessary.

## 5. Practical evidence and handoff templates

Use only material fields. `Unknown` is a valid value; do not fill it from a desired specification.

```yaml
audio_review:
  source_id_revision: Unknown
  evidence_state: user_report_only
  inspected_by_method: none
  inspected_ranges_channels: none
  reported_or_observed_symptom: ""
  inference: "hypothesis, distinct from observation"
  accepted_locks: []
  one_test: ""
  one_change_if_supported: ""
  uninspected_scope: "all audio"
```

| Property | Requested / intended | Verified / method / scope | Unknown / dependency |
|---|---|---|---|
| Duration | User target or approved edit length | Actual property only when read/measured | Natural take and final edit may differ |
| Loudness / peak | Destination-specific target if supplied or verified | Actual metric, units, method and measured range | No meter run means no measurement |
| Words | Exact approved script / lyrics | Actual audible/transcribed match with method | Unheard or uncertain words stay unverified |
| Sample rate / channels | Requested delivery spec if relevant | Actual file metadata | Do not infer from extension |
| Sync | Exact, approximate or deliberately offset requirement | Actual combined interval reviewed by video | Carrier/tool/timing readiness is separate |

When a source or accepted take changes, mark affected cues, captions, picture sync and delivery documentation `review_required`; do not erase the approved words or hard sync requirement. Producer owns audio, video owns moving-picture/AV review, and output-critic-iteration remains the static-image review owner.
