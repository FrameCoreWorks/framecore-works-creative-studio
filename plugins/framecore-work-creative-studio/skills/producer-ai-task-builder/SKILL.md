# Legacy audio skill alias

Before final delivery of a substantive authored, revised or generated creative artifact, automatically apply [output review](../pipeline-core/references/loop-protocol.md#automatic-output-review). Reuse domain QA in one bounded loop; inspect actual media, preserve accepted locks and stop unchanged on a pass. This does not run for greetings, menus or onboarding questions.

This retained entrypoint exists only because plugin overlay updates cannot delete the former skill directory. For every substantive audio request, apply the conditional [Research Evidence](../research-evidence/SKILL.md) gate and continue with [Audio Production Director](../audio-production-director/SKILL.md). Do not start a second audio workflow here.

ProducerAI is now mentioned here only as the former name of Google's Flow Music product. It is not this skill's current title or a bundled connector. The plugin does not run Flow Music, generate audio, or provide persistent provider access.
