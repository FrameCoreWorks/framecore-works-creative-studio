# Legacy audio skill alias

This retained entrypoint exists only because plugin overlay updates cannot delete the former skill directory. For every substantive audio request, follow the mandatory [Research Evidence](../research-evidence/SKILL.md) preflight and continue with [Audio Production Director](../audio-production-director/SKILL.md). Do not start a second audio workflow here.

ProducerAI is now mentioned here only as the former name of Google's Flow Music product. It is not this skill's current title or a bundled connector. The plugin does not run Flow Music, generate audio, or provide persistent provider access.
