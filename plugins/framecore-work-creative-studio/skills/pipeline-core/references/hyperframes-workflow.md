# Motion Graphics

Motion graphics supports several coded-video production paths. Use the shared runtime selection policy (FrameMotion: `skills/framemotion/references/code-based-motion-graphics.md`); HyperFrames is one option, not the default selected by this reference or its filename.

Use Motion Graphics (FrameMotion plugin, `framemotion`) for general code-based motion planning and HTML/SVG/Canvas/GSAP composition, including HyperFrames when selected. Use Remotion Video (FrameMotion: `skills/framemotion/remotion/REMOTION.md`) for a React/TypeScript composition and the FrameCut plugin (`framecut`) for a footage-first edit. A plan does not imply an installed renderer. Inspect the active runtime before promising playback, measured duration, export or delivery.

Required inputs:

- Motion Direction Contract
- Storyboard Contract or scene structure
- Copy Pack
- asset list
- render constraints

Expected output:

- Motion production brief (existing internal HyperFrames Production Brief type retained for compatibility, not engine selection)
- scene timing
- composition structure
- GSAP animation notes
- captions and overlays
- render QA checklist
- delivery manifest requirements
