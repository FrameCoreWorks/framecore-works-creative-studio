# HyperFrames Workflow

HyperFrames is a coded-video production path.

Use [HyperFrames Workflow](../../hyperframes-workflow/SKILL.md) when the user requests that runtime or an HTML/GSAP composition. Use [Remotion Video Production](../../remotion-video-production/SKILL.md) for a React/TypeScript composition and [OpenCut Video Studio](../../opencut-video-studio/SKILL.md) for a footage-first edit. A plan does not imply an installed renderer. Inspect the active runtime before promising playback, measured duration, export or delivery.

Required inputs:

- Motion Direction Contract
- Storyboard Contract or scene structure
- Copy Pack
- asset list
- render constraints

Expected output:

- HyperFrames Production Brief
- scene timing
- composition structure
- GSAP animation notes
- captions and overlays
- render QA checklist
- delivery manifest requirements
