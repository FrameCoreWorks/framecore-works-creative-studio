# Campaign asset card

Use per requested asset or explicit variant family. Retain context rather than restarting discovery; missing fields remain Unknown and block only dependent work.

- Campaign ID / asset ID / revision / status:
- Audit and strategy revisions / selected angle:
- Business role, audience situation/stage and primary message:
- SKU/variant, offer conditions and destination:
- Claim IDs / substantiation scope / qualifiers:
- Exact copy, language, approval status and CTA:
- Placement, composition/ratio and current specification source/date or provisional status:
- Desktop/mobile or channel adaptation requirements:
- Source aliases/revisions, reference roles, actual availability and rights evidence:
- Product fidelity locks: geometry, label, logo, color/material, quantity/volume:
- Person source/status: real_authorized_person / synthetic_presenter / actor_portrayal / Unknown:
- Identity carrier and permitted expression/wardrobe variation when recurring:
- Visual mechanism, camera/light, action/contact and allowed changes:
- Existing owner / next deliverable / dependent asset revisions:
- Prompt contract and exact target surface when requested:
- Execution readiness / actual authorization, input binding, cost and retry scope:
- QA observables / actual inspection evidence and limits:
- Measurement ID / proposed test hypothesis and comparison basis:
- Delivery specification / actual file path and status when available:
- Blocked items / one next action:

Keep planned, prompt_ready, generated_uninspected, reviewed, accepted and published states distinct. A source image or prompt is not evidence of a generated result. Approved wording and synthetic presenters never establish product claims or customer experience.
