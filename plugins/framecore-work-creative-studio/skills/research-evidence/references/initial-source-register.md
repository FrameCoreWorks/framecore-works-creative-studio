## Platform

P01. OpenAI, Building plugins: https://developers.openai.com/plugins/build/plugins

Official documentation read during this build. Describes a portable root plugin.json, skills discovery and OpenAI metadata/compatibility handling. Supports a skills-only plugin architecture. Does not prove this package was installed or that every host exposes identical tools.

P02. OpenAI, Skills: https://developers.openai.com/plugins/build/skills

Official documentation read. Supports focused skill entrypoints and task-relevant supporting resources. Local link validation is not proof of live ChatGPT/Codex retrieval. Cross-skill resource loading remains a host-test item.

P03. OpenAI, Package your plugin: https://developers.openai.com/plugins/build/plugins

Official documentation rechecked on 2026-09-23. Describes the portable root plugin.json, root skills/ discovery, OpenAI presentation metadata under extensions.com.openai, and .codex-plugin/plugin.json as a compatibility fallback. It also distinguishes personal/repo marketplaces for local authoring and testing from public plugin submission. This confirms the package route, not account-level availability or installation of this candidate.

P04. OpenAI, Skills: https://developers.openai.com/plugins/concepts/skills

Official documentation opened and checked on 2026-09-23. Skill metadata is initially used for matching; full instructions load when a request matches or explicitly invokes a skill. Skills can work without bundled MCP when packaged instructions/resources suffice. Implementation consequence: each directly callable creative skill must link to the shared mandatory research workflow; a local link/manifest check still does not prove live retrieval.

## Image targets

I01. Google DeepMind, Gemini Image prompt guide: https://deepmind.google/models/gemini-image/prompt-guide/

Official guide inspected. It recommends describing subject, action, setting, style and composition; quoting desired text; assigning clear reference identities; and iterating specific details. This is family-level prompting guidance, not proof that every Gemini version or UI has identical controls.

I02. Google AI for Developers, image generation: https://ai.google.dev/gemini-api/docs/image-generation

Current search-index content identified several Nano Banana variants, including a newer Lite variant. Detailed per-version contract was not fully audited here. Treat names as discovery leads until the relevant page and actual surface are read; do not port API fields to Gemini chat automatically.

I03. Black Forest Labs, FLUX.2 pro/max prompting: https://docs.bfl.ai/guides/prompting_guide_flux2

Official guide sections inspected. It states that this FLUX.2 guidance does not use negative prompts and recommends describing the desired result positively. It discusses text in quotes, position/type roles, object-bound color descriptions and structured prompt organization. Do not infer exact color accuracy, a universal best prompt length or support in every FLUX sibling. Native consumer controls need their own check.

I04. ByteDance Seed, Seedream 5.0 Pro announcement: https://seed.bytedance.com/en/blog/beyond-generation-it-understands-design-introducing-seedream-5-0-pro

Official announcement inspected. It demonstrates local editing with spatial input, color/material changes, multi-image composition and layer-separation concepts. These are vendor demonstrations, not a verified tool schema or local benchmark. Do not promise downloadable layers, transparency or exact preservation on an unverified user surface.

I05. Qwen, Qwen-Image-3.0 announcement: https://qwen.ai/blog?id=qwen-image-3.0

The official indexed announcement was available and identified a July 2026 release. Direct page extraction returned no readable lines. Detailed prompting behavior and availability remain partial evidence, requiring a readable official page/model card or UI check. Do not mistake Qwen-Image-2512, editing variants, 2.0 and 3.0 for one interchangeable contract.

I06. OpenAI, image-generation tool: https://developers.openai.com/api/docs/guides/tools-image-generation

Current official content inspected through search. It distinguishes the reasoning model from the image-generation tool/model and documents image/edit inputs and tool-specific output controls. This is API documentation, not evidence that a ChatGPT or Codex native tool exposes those settings. New API model names do not override a user's native-model policy or prove host availability.
