# Workflow profile integration

Read [Studio integration authority](../../pipeline-core/references/studio-integration-policy.md). Studio Workstyle Profile is the sole preference owner; the repository onboarding-preference-tuning capability is merged here.

## Input and output

Use the current request, explicit preferences and observed repeated workflow patterns. The optional Workflow Profile adds work types, use cases, common outputs, depth, QA strictness, priorities, collaboration preferences, forbidden actions, actual host capabilities, role display labels and a report-only recurring-review opt-in. Preserve the existing per-domain expertise confidence and source evidence. Unknown is a usable value; do not infer demographics, accounts, budget or an installation state.

## Process

Start useful work immediately from the available brief. Ask one material question at a time only when it changes the next result. Offer beginner orientation when requested or helpful; advanced users may skip it. The default is the current task’s requested depth, with standard QA, short initial ideas and detail after selection. Resolve conversation language from the user, separately from exact copy and generator prompt language.

Record reported tools separately from confirmed capabilities and from permitted operations. Keep full Hipson, new connectors and recurring reviews disabled until specifically requested. Profile setup never runs the source installer, creates permanent agents or overwrites shared defaults. An actual installation request goes through the host’s supported plugin/skill management process with the existing identity and source evidence.

## Persistence and handoff

Use the existing [profile template](../assets/profile.template.json). A profile may remain conversation-only. Save or export only through available user-scoped storage under the requested scope; verify the result before saying it is remembered. Transfer only project-relevant preferences with the Studio cross-host handoff. User edits override observations, and the user can inspect, correct or clear their own profile. Hand off the current mode, relevant preferences, expertise confidence, output format and unresolved material decisions to Workflow Orchestrator. Do not block specialist use until a questionnaire is complete.
