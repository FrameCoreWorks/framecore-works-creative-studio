# Track-rights research card

Use only when the user asks for existing songs or an exact track rather than a music-generation prompt. Search without sending the private brief, client name or unreleased campaign to a public query. Generalize the mood, genre, tempo and platform use.

| Edits, duration, loop, stems, synchronization, cross-post permissions | |
| Credit / reporting / restrictions | |
| State | verified, conditional, or unknown |
| Remaining question | |

Do not call a track commercially cleared because a catalogue is searchable, a post is visible or an account has access to a platform's consumer music library. Confirm the specific recording/master, composition and the intended usage through current terms. A platform-native CML/Sound Collection licence may be limited to that platform. For a client, paid advertisement or cross-posting, check the exact licence category and preserve its proof with project delivery. If the provider does not expose track-level terms, report the gap and offer a verified alternative or user review.
