# Teacher administration templates

These are blank structures, not records of completed events. Use the [teacher workflow](../../references/teacher-workflow.md). Keep sensitive identifying information out of shared examples, research and external tools.

## Planned activity

- Topic and intended objective: [to fill]
- Intended group, date and duration: [to fill]
- Planned actions and materials: [to fill]
- How the teacher intends to check the objective: [to fill]
- Necessary arrangements confirmed / still pending: [to fill]
- Status: **planned**, not evidence of delivery.

## Factual activity note

- Actual date and scope: [verified fact or Unknown]
- Source of the account: [teacher-provided note / actual observation / other]
- What happened: [observable actions only]
- Work or evidence available: [non-identifying description]
- What can be concluded from that evidence: [bounded statement]
- What remains unknown: [to fill]
- Next action proposed, not yet completed: [to fill]

Do not turn intended objectives into achieved outcomes. Do not infer attendance, progress, intervention success, signatures or institutional approval. A blank field is preferable to an invented fact.

## Parent communication

Use the user's requested language and author voice. Confirm event facts and required action before producing ready-to-send text. This template creates content; it does not authorize sending.

- Subject: [specific topic]
- Purpose: [why the message is being sent]
- Confirmed information: [date/time/place/materials only if known]
- Parent action and deadline, if actually required: [confirmed request]
- School contact route: [provided public/approved route]
- Open points to resolve before sending: [not included as invented facts]

Avoid including another child's details or diagnosing behavior. If a difficult situation is involved, describe documented actions respectfully and distinguish observation from interpretation.

## Worked synthetic note in Polish

**Przykład fikcyjny, nie dokumentacja zdarzenia.**

**Plan:** Uczestnicy mają podać argument oraz wskazać informację, której brakuje do decyzji.

**Dostępna informacja w przykładzie:** Prowadzący otrzymał trzy anonimowe odpowiedzi. Dwie zawierają argument i pytanie o brakującą informację. Jedna zawiera sam wybór.

**Wniosek ograniczony do tych prac:** W dwóch odpowiedziach występują oba wymagane elementy. Trzecia wymaga uzupełnienia. Te dane nie określają postępu całej klasy ani zmiany względem wcześniejszych zajęć.

**Propozycja następnego kroku:** Pokazać przykład rozróżnienia wyboru i uzasadnienia, potem zebrać nową krótką odpowiedź. Jest to propozycja, nie zapis wykonanej czynności.
