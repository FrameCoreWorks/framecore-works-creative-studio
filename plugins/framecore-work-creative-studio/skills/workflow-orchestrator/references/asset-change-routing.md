# Route a changed asset without restarting the project

Use when a shared reference, master, approved text, audio track or project file changes. Keep the existing studio contract and permissions. This is Studio workflow synthesis, based on the provenance/revision distinction documented in [asset lifecycle](../../delivery-documentation/references/asset-lifecycle-and-dependencies.md). It adds no new owner or execution integration.

## Decide the scope

Identify the changed asset ID and old/new revision, actual delta, dependents, preserved locks and the requested artifact. Use a small table for a simple project. For a larger project use the manifest helper described by Delivery. Do not invent a file's existence or treat a plan as a produced master.

| Change | First responsible owner | Recheck downstream |
|---|---|---|
| Product geometry, label, identity or garment reference | Image Prompt Architect for compilation; Commercial Visual Director if the concept/layout must change | Affected stills, boards and video continuity carriers |
| Headline, price, CTA or editorial wording | Copy Voice, with Research Evidence for consequential claims | Exact-copy prompts, layout fit, voice/caption wording where that same text is used |
| Narrative dialogue, action or scene turn | Screenplay Story Architect | Sequence, protected dialogue windows, board labels and selected shot prompts |
| Lyrics, VO pronunciation, arrangement or audio master | Audio Production Director | Music-video timing, lip-sync evidence, cue sheet, captions and AV delivery |
| Shot order, timing or continuity state | Storyboard Sequence Architect | Boards, clip prompts and transition assumptions |
| Static board layout or reference grouping only | Storyboard Board Architect | Its labels/readability; timeline only if the temporal plan actually changed |
| Current generator operation/limit | Research Evidence, then relevant prompt owner | Only model-dependent compilation and feasibility |
| File moved with verified unchanged content | Delivery Documentation | Locator and actual access, not automatic creative reapproval |

The static critic inspects actual stills, Video Prompt Architect inspects video evidence, and Audio Production Director handles audio evidence. A route selects a responsibility; it does not assert that a separate agent or tool ran. A mixed change can have several affected artifacts but should still have one short next action.

## Carry a compact change packet

Use: changed input/version; what changed; references/copy/identity locked; direct and transitive dependents; inherited research and authorization; affected acceptance criteria; owner; needed evidence; current state. Preserve the historical approval and record which part no longer supports the current state. Keep strict requirements strict while separately stating execution readiness and observed outcome.

Example: product-front r002 becomes r003 with a corrected label. A square poster depends on r002, and its portrait adaptation depends on that poster. Both require label-fidelity reassessment; a separate lyric draft does not. This dependency finding is not permission to regenerate either image or to rewrite the slogan. If the user requested only a revision plan, finish with the plan.

When only a prompt pack was requested, provide a complete pack with unresolved future asset dependencies identified. A future master does not block authoring a useful specification. Editing an actual source still requires that source and a supported authorized operation.

## Resume honestly

Read the current manifest or user-supplied checkpoint. Confirm which content and evidence are actually available now. Recover missing facts from the existing task record where possible. Do not promise persistent memory or treat a stale checkpoint as a live database. Update only records supported by current work.

Stop after the requested artifact and affected checks are complete. A dependency map does not authorize unrelated changes, public uploads, messages, paid tools or publication. Reuse unchanged research; refresh only new creative decisions or changed factual/tool conditions under the existing research gate.
