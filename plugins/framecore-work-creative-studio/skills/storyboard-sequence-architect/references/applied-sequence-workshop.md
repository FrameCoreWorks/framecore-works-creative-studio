# Applied sequence workshop

Use when a script must become an executable plan without losing the reason a scene works. This original Studio exercise supplements the existing continuity contract. It does not turn a still reference board into a timed sequence or make a planning value a measured property.

## Begin with information, then coverage

List only the visible/audible facts a viewer must perceive. For each, choose the shot that can actually expose it at useful scale. A tiny mechanism and two distant faces may need different coverage; a relational exchange may work in one held frame. Do not split every line into its own shot or add camera movement to signify production value.

Use the [state and speech ledger](../assets/state-and-speech-ledger.md) when a handoff is fragile. Treat each material object as a state transition: where it starts, who moves it, what makes contact, where it ends. Separate legal ownership, hand occupancy and screen position. If a source changes one of these, reassess the dependent beats, not every accepted shot.

## Protect dialogue without freezing all motion

A protected speech window records the exact line, speaker, timing basis and what must remain perceivable while it is delivered. It is an original planning aid, not an API parameter. Choose the protection according to the scene: mouth visibility for an on-camera line, listener response for a withheld answer, or stable attention while essential information arrives. A voice-over need not show a mouth.

| Conflict | Smallest candidate correction |
|---|---|
| A camera reveal competes with the essential line | Move the reveal before/after the line or hold the relevant subject |
| An action hides the speaking mouth required by the brief | Delay the occlusion or use a permitted view; do not relabel exact sync as approximate |
| Locked speech cannot fit a fixed target naturally | Name the conflict; propose a longer unit, another permitted structure or separately approved text change |
| A listener appears to speak the other person's line | Restore speaker ownership and the intended silent response |

No universal words-per-minute value establishes feasibility. If there is no recording, label windows as estimates. A requested exact runtime requires later measurement against the actual timebase. Planned future carriers may be documented for prompt-only work; strict execution remains pending until bound and checked.

## Plan accessible communication before the board

[W3C media planning guidance](https://www.w3.org/WAI/media/av/planning/), accessed 2026-09-28, distinguishes needs arising from audio content and visual content and recommends assigning accessibility work during planning. Applied here: note which essential information is carried by speech, sound or image, then hand requested caption/transcript work to Audio Production Director and actual placement/AV review to Video. This is a planning handoff, not a WCAG compliance certificate.

## Research basis for continuity

[Adobe's original continuity-editing guide](https://www.adobe.com/creativecloud/video/hub/ideas/what-is-continuity-editing-in-film.html), accessed 2026-09-28, explains how eyelines, spatial relationships, action matches and sound bridges support orientation, while deliberate discontinuity can serve an authored purpose. Treat those as tools, not rules overriding the user's chosen form. The ledger and dialogue-window procedure are original Studio synthesis.
