# Reusable copy and format card

Original Studio planning asset, 2026-09-28. This is an optional internal worksheet,
not a final prompt or a required intake form. Populate only from the current
brief, selected copy and actual sources. Missing facts remain Unknown. Do not
turn row labels, IDs or blank fields into artwork text.

## Copy relationships

| Copy ID | Exact approved string | Required? | Role | Paired fact/qualifier | Allowed breaks |
|---|---|---|---|---|---|
| Record only needed items | Preserve exact source | Yes/no from brief | Entry/support/retrieval | Identify the real relation | Locked or stated reflow |

Keep spelling and line arrangement separately. Compare the actual string and
its pairing after each requested adaptation; a correct price beside the wrong
item is still a failure. A source logo stays an asset, not a text reconstruction.

## Per-format decision

| Question | Record |
|---|---|
| Requested artifact/use | Ratio/dimensions if supplied; actual viewing context |
| Invariant | One sentence describing the selected mechanism |
| Permitted change | Crop, scale, padding, recomposition or approved content change |
| Actual feasibility evidence | Available source, dimensions and content bounds, or Unknown |
| First read | The element that should win attention |
| Information territory | Where all compulsory strings fit and remain paired |
| Relevant safe area | Verified source value or explicit design assumption |
| Method | Integrated raster, explicitly requested layers/code/vector, or production handoff |
| Prospective checks | Exact copy, mechanism, reading and relevant technical fact |
| Result status | Specification/prompt only, actual artifact available, or inspected result |
