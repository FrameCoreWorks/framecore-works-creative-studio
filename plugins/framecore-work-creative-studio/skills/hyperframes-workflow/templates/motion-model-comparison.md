# Controlled motion comparison packet

This is an evaluation design, not authorization to call a model/provider, install tools or spend money. Keep the selected model in normal production. Record every unexecuted trial as not_run.

## Two separate questions

1. Model contribution: identical brief, approved assets, prompt, renderer/version, environment, tool permissions, output format and repair budget.
2. Production-system contribution: each system's best allowed workflow, with all tools, interventions and resource usage disclosed.

Do not mix the rankings or let one model inspect another's result before independent runs finish.

## Minimum useful sample

Use six original briefs: brand ident; dense but readable kinetic type; product workflow; truthful data explanation; geometric educational explanation; spatial/material scene with timed sound. Include at least one light, quiet design and one vertical layout. Use three independent repeats per condition where authorized. Do not choose only the best seed or discard failed exports. Plan sample size and stopping rule before running.

Record wall time, tokens, actual billed cost or clearly labeled estimate, manual interventions, number of repairs and render time. Missing cost is Unknown, not zero.

## Review

First report technical completion, locked-copy/asset fidelity, runtime, duration and playable encoded deliverable. Keep failures visible in the denominator. Then present anonymized full films in randomized order to reviewers; hide source model/branding until scoring. Review at the same display size and sound level. Use the same target-viewing context.

Score 1–5 with an explanation and time range for: message clarity, typography/readability, timing, continuity, originality/brief fit, and sound (N/A only for approved silence). Anchors: 1 unusable; 3 usable with material repair; 5 coherent, legible and purposefully finished with no identified material defect. Do not turn an unobserved modality into a score.

Report per-brief distributions, pairwise preferences, ties, reviewer disagreement, sample size, failure rate and uncertainty. State practical limitations instead of extrapolating a small sample to universal superiority. Keep objective defects separate from aesthetic preference. Establish acceptance thresholds before viewing results, and preserve artifacts for reproducibility.
