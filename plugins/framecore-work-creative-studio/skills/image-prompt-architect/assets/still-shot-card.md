# Reusable still shot card

Original Studio planning asset, 2026-09-28. Use only fields that change the next
creative decision. This is a planning template, not a final prompt, provider
request, mandatory form or generated-file manifest. Empty fields are Unknown,
not facts to invent. A short request can use one sentence instead.

| Decision | Record for this image |
|---|---|
| Picture's job | The relationship or feature the viewer must understand |
| Output operation | New still, source-bound edit, independent variant, or prompt-only plan |
| Source authority | Actual source per critical property; suppression boundaries |
| Coverage limit | Relevant unseen/ambiguous feature and why it matters |
| Contact / ownership | Actor, anatomical side, supported object and visible interaction |
| View | Frame size, camera relation, perspective behavior; only approved changes |
| Useful focus | Features that must be readable together |
| Material response | One consequential visible response for each hero surface |
| First read | What should win attention; competing element to control |
| Exact visible copy | Approved string inventory, or explicit no-copy |
| Continuity requirement | Strict or authorized approximate, separately for each property |
| Input readiness | Available/bound source or explicitly planned future dependency |
| Open creative trade-off | Decision needed only if it affects a required result |
| Prospective test | Observable target change plus protected property to compare |

## Completed fictional planning example

- Job: an unchanged portrait wearing a source-supported jacket.
- Operation: garment-only edit of the available portrait base.
- Authority: portrait for face/body/pose/scene; jacket photo for construction.
- Coverage: only the visible front is required; the back remains Unknown.
- Interaction: collar wraps the existing neck; sleeves meet the existing arms.
- View/focus: retain camera and crop; keep face and visible closure readable.
- Material: matte canvas shaped by the established portrait light.
- Copy: none; no added mark or caption.
- Requirement: strict likeness and garment construction; readiness depends on
  the real portrait and jacket being bound to the edit request.
- Test: compare identity to the portrait and collar/zip/pockets to the garment.

See the [complete prompt](reference-transfer-worked-examples.md#example-a-identity-from-a-portrait-construction-from-a-jacket).
The hypothetical card does not establish that any actual image exists or passes.

## Compile without template residue

Replace the working notes with one standalone prompt containing applicable
visual facts and exact copy. Do not paste unresolved alternatives, invented
aliases, source-evidence claims or empty form fields into a supposedly final
prompt. A future-master dependency may be stated as a condition for execution;
it must not be described as an already attached asset. Stop at the requested
artifact and use the existing compiler's research and execution boundaries.
