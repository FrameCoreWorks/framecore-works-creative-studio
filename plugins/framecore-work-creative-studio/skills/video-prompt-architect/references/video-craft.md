# Video craft: causal direction, continuity, performance and repair

Integrated runtime knowledge synthesized from the full audits of four approved FrameCore Works video prompt packages. Draft basis: 2026-09-21. This is stable production craft, not a current model capability table, API schema, executed prompt benchmark, or guarantee of a rendered result.

Current model names, versions, UI/API surfaces, controls, limits, and community-reported behavior must be checked separately through the research workflow before a generator-specific prompt is presented as current. A request to write a prompt alone does not authorize a paid provider, upload, or media generation. Carry separately granted operation authorization through handoffs without requiring the user to repeat it.

## 1. Responsibility and use

The video specialist converts an approved direction, script, shot card or sufficiently clear single-shot brief into a feasible video prompt. It should not silently change an approved premise, screenplay, shot order, identity, product, wardrobe, visible copy or spoken line.

When approved storyboard or shot cards are supplied, preserve their shot IDs, durations, narrative functions, reference roles and continuity commitments. If an instruction cannot work, return a specific conflict and the smallest proposed change. Do not invent a replacement sequence and claim it is the approved version. Sequence and shot-card authoring belongs to [storyboard-sequence-architect](../../storyboard-sequence-architect/SKILL.md); static board layout and exact visible labels belong to [storyboard-board-architect](../../storyboard-board-architect/SKILL.md). These are separate initial runtime modules, not evidence of target-host behavior or render quality. A storyboard board, keyframe label or shot card is not automatically a bound carrier for the independent request.

Useful output types are distinct:

- creative exploration: assessable directions, not fake final execution packets;
- neutral production blueprint: complete intent, not a claim of native API syntax;
- model-adapted prompt: ready to paste only after relevant input and surface checks;
- structured planning packet: JSON/YAML representation, explicitly not an API body;
- execution handoff: exact available input binding, settings, consent and verification state;
- diagnosis: observable failure, a hypothesis, bounded repair and acceptance test.

Stay within the requested artifact. Writing a prompt does not authorize generation, an image keyframe, a paid retry, installation or upload. A planned external operation is not evidence that an upload or render occurred.


## 2. Separate the creative contract from the execution contract

Resolve three independent axes:

| Axis | What it answers | Examples |
|---|---|---|
| Operation | What transformation is requested? | T2V, I2V, reference-conditioned generation, edit, V2V, extension, first-last, presenter/lip-sync |
| Context transport | How does this request receive truth? | text only, attached references, extracted approved frame, bound source clip, verified shared context inside one job |
| Shot construction | What is the editorial unit? | one continuous shot, native multishot job, several independent shots |

These are not interchangeable labels. A fresh T2V request describing yesterday's ending is not native extension. Several independent prompts in one message do not become a shared-context multishot job. A close insert followed by a return shot is editorial construction, not a continuous shot merely because the header says so.

The creative contract contains objective, source truth, action, camera, sound, locks and acceptance criteria. The execution contract contains verified model/surface, operation, real input bindings, supported controls, output constraints and authorization state. Keep volatile controls outside stable craft. Do not ask about API or a wrapper unless the user has explicitly introduced that context; infer the ordinary interface from supplied context and ask only about a decision that actually blocks the requested result.

If the exact surface is unresolved, produce a clearly labelled neutral blueprint when useful. Do not make up syntax, aliases, seeds, negative fields, resolution or reference limits. Model-aware adaptation may leave simple prose unchanged when both verified surfaces support the same practice. Forced stylistic differences are not evidence of adaptation quality.


## 3. Minimum useful intake

Start with what is already supplied. For an ordinary prompt, resolve only:

1. What should the viewer understand, feel or do?
2. What is visible, and what changes?
3. What operation and source material are available?
4. What duration/aspect or delivery constraint matters?
5. What must remain exact?
6. Is speech/audio essential, and is the text approved?
7. What observable result counts as success?

Quick mode reduces conversational friction, not QA. A usable brief should move straight to the artifact. Deep mode is appropriate for unresolved direction, a campaign system, recurring characters, strict product proof, hard continuity or repeated failure. Show only the next material decision, not the entire internal form. Three directions are useful for real exploration, not a mandatory tax on every precise request.

For a vague product request, source truth may be the decisive question. For exact dialogue, timing may be the question. For a repair, the actual clip or a clearly qualified user report may matter more than asking for a new brief. For a model capability question, answer the question rather than forcing a prompt.


## 4. Truth, control and freedom

Allocate prompt detail by consequence, not evenly across a template.

- **Truth:** approved identity, exact product/SKU, garment construction, copy, source timing, authorized voice or location geometry. Conflicts require a chosen authority.
- **Control:** a decision needed for this outcome, such as visible contact, speaker ownership, camera side, event order, terminal state or a narrow edit range.
- **Freedom:** low-risk incidental dressing, noncritical background texture or restrained ambience the generator may interpret.

For a bottle demonstration, pump mechanics and hand contact may be truth-critical; the exact texture of a distant wall is not. For a drama close-up, the actor's intention and listener relation matter more than cataloguing every prop. For a fashion wide shot, silhouette and gait outrank individual skin pores.

Do not describe invisible detail as if it were sourced. A portrait cannot prove a person's exact unseen body. A front packshot does not prove rear ports or an internal hinge. If the requested action reveals unknown truth, request the missing angle, reduce the view or clearly keep the work at concept level.


## 5. The temporal spine

A video prompt defines a transition, not just a beautiful frame. Use the smallest spine that makes the change intelligible:

`opening state -> trigger/preparation -> primary action -> contact or reveal -> consequence -> recovery/terminal state`

Not every shot needs all labels. A breath and a gaze shift may require only an opening, one motivated change and a hold. A pump, pour or handoff needs the complete causal chain. A surreal transformation needs its own intelligible world rule; it need not obey ordinary mechanics, but should not accidentally masquerade as truthful product proof.

For each important beat ask:

- What is visibly true before it starts?
- What causes the change?
- Can the audience see that cause?
- Which object/body/material responds, with what delay and direction?
- What is true afterward?
- Why can the next beat start from that state?

Sequential actions: reach before grip; grip before lift; cap opens before pour; question before reaction; contact before recoil. Simultaneous actions: camera tracks during a walk; cloth follows body acceleration; a contact sound occurs at contact. Do not use a long chain of “while” clauses to hide sequential dependencies.


## 6. Duration, load and feasibility

Duration is a budget shared by preparation, visible action, speech, camera movement, reaction and comprehension. A longer model maximum is not permission to pack more unrelated events into a shot.

Useful starting heuristics, not model guarantees:

- a few seconds: one gesture, reveal, texture event or reaction;
- roughly five to ten seconds: one complete causal action, perhaps with a short line or a small setup/payoff;
- a longer short clip: a richer arc or a verified multishot construction, still with breathing room.

Estimate load across subject count, contact difficulty, strict references, camera/parallax, environment motion, dialogue, exact text, transformation magnitude and cuts. Simplify when several difficult dimensions compete. A tiny two-hand mechanism plus a fast orbit, long speech and changing wardrobe has several failure causes before the first word of the prompt is improved.

Prioritize the shot's decisive evidence. If the mechanism is the point, stabilize camera and speech. If the line is the point, frame the mouth and reduce hand action. If a fast athletic phrase is the point, reduce facial microdetail and secondary characters. Separate macro proof from full-body geography when one continuous transition would be physically or temporally implausible.

Time ranges must fit the intended duration, have no accidental gaps or overlaps, and correspond to causal beats. Natural timing is often sufficient. Timestamp syntax, frame precision or strict edit control must not be claimed without surface support. A timing estimate based on reading text is not measured delivery time.


## 7. Camera is a decision, not decoration

Choose in order: purpose -> visible evidence -> scale and side -> blocking -> camera path -> perspective/focus -> terminal composition.

| Purpose | Useful choice | Typical failure |
|---|---|---|
| Establish geography | wide or medium-wide with clear entry/exit | close chaotic action before spatial context |
| Prove a mechanism | stable close shot with contact in focus | orbit hides the critical contact |
| Intimacy or dialogue | stable medium-close/close, readable eyes and mouth | extreme motion competes with a short line |
| Reveal form | controlled slider, arc or shaped light | product and camera spin in opposing paths |
| Follow action | lateral track or readable follow distance | camera crosses the route and reverses screen direction |
| Show reaction | hold after cause | expression peaks before the event |
| Land a payoff | stable readable terminal frame | ending cuts away before comprehension |

A useful path states starting position/height, side, distance, direction, speed profile, what it follows/reveals, and where it ends. “Dynamic cinematic camera” specifies none of these.

Movement families:

- locked-off: performance, mechanism or environment carries change;
- pan/tilt: rotation from a stable position;
- push/pull: distance changes for emphasis/context;
- lateral track: subject relation and screen direction stay readable;
- arc/orbit: form and background relationship change, with higher geometry risk;
- crane/pedestal: vertical relation changes;
- restrained handheld: motivated operator correction, not random noise;
- whip/crash/rapid chase: one deliberate punctuation with readable states before and after;
- rack focus: attention changes between defined planes, not a substitute for action.

One dominant purpose per short shot is a good baseline. Compatible secondary reframing is allowed. Do not turn this into a mechanical ban on nuanced camera movement.


## 8. Perspective, framing and focus

Camera distance determines perspective; a focal-length number alone does not create a photographed relation. Near wide perspective exaggerates near objects and parallax. A more distant compressed relation can protect facial/product proportion while reducing apparent depth. Macro demands limited movement and precise focus. Treat lens numbers in a prompt as intent unless actual camera metadata/control exists.

Scale sets information capacity. A wide frame can communicate gait, setting and relationships, but not exact pores or a small label. A macro can prove a seam or button but not the whole body's choreography. Select depth of field for the required evidence: very shallow focus may undermine hands, two speakers or product controls.

Rack focus needs two defined planes, a narrative reason, timing and an ending. Avoid combining macro focus, a rapid orbit and several transfers of focus merely to sound technical. When a product label must be read, keep its plane large enough, sufficiently frontal and stable, with controlled reflections.


## 9. Blocking, axis and contact

Track camera side, subject facing/travel direction, eyelines, entrance/exit, depth positions, initiating/reacting actor, hand/product side and object orientation. For a dialogue two-shot, stable left/right ownership helps the viewer understand who addresses whom. For action, establish participants, obstacle and route before close detail.

A deliberate axis change is possible through a visible camera move, a neutral head-on shot, an orienting insert or a clear subject reorientation. An unexplained flip in an independent generation is a continuity risk, not added energy.

For contact, specify approach, contact surface, grip or applied force, object/material response, release and end state. Do not “fix” a necessary hand demonstration by hiding the hands. Enlarge the interaction, reduce camera demand or separate a mechanism insert from the performer's reaction.

For energetic action, design one readable phrase: preparation -> approach -> peak/contact -> consequence -> recovery. Fictional cinematic action does not require operational instructions for real harm. Camera should show the dramatic interaction, not conceal missing causality behind shake.


## 10. Four motion layers and physical response

Separate before combining:

1. subject: face, body, hand, product, prop or vehicle;
2. camera: position, tracking, arc, reframe;
3. environment: wind, rain, foliage, fabric, crowd, steam;
4. optical/editorial: focus, blur character, cut, speed change or transition.

Choose a leader. A shot where every layer is aggressive is often unreadable. Secondary motion should follow cause: hair and cloth respond after body acceleration; wind affects exposed elements consistently; shadow and highlight respond to light/material/camera geometry.

For bodies, resolve intention/gaze, anticipatory weight shift, torso/hip motion, limb timing, support/contact and recovery. For a turn, feet, pelvis, torso and head do not all teleport simultaneously. For walking, the ground contact, body translation and gait phase must agree.

For liquids, know source opening, amount, viscosity, gravity path, contact, splash/residue and settling. For mechanisms, know hinge/cap/button/zip/pump geometry and state. For reflections, identify the actual object and light relationship; a changing highlight is not a second physical object. Do not decorate a calm interior with independently moving dust, hair and curtains without a motivating source.


## 11. References and continuity: property-level authority

Assign roles by property, not just “reference 1”. One reference can supply multiple compatible facts, but its authority must be explicit. Typical roles: identity, product, wardrobe, location, composition, start/end state, style, camera, motion and authorized audio/voice.

For each asset record:

| Property | Example |
|---|---|
| Identity and accessibility | approved garment image, accessible file, not merely a mentioned name |
| Controls | seam placement, fabric, buttons and silhouette |
| May influence | how visible folds behave if supported by the source |
| Must not transfer | different face, room, color grade or incidental branding |
| Required units | shots where this truth is visible |
| Binding status | planned / available / bound / submitted, with evidence |

Existing semantic aliases and verbatim suppression instructions from an approved reference contract are preserved. Do not rename by upload order after authority is established. A final prompt names only assets actually intended and available for that request; syntax must match the verified surface. An attached chat image does not prove that a later tool request received it.

Strict continuity requires an appropriate carrier for every independent request, but a carrier does not guarantee a correct output. Distinguish requirement (`strict`), input readiness (`carrier-ready`) and observed outcome (`accepted after QA`). Text and seed reuse may support approximate consistency; neither proves identity or spatial continuity. Missing carriers change readiness, not the requirement. Adopt approximate continuity only if that was already the requested level or the user accepts the proposed relaxation.


## 12. Choose a continuity strategy deliberately

| Strategy | Use | Boundary |
|---|---|---|
| Independent text generation | exploration, deliberate reset, loose world resemblance | no strict identity/product continuity claim |
| Independent reference-conditioned | separately editable campaign or narrative shots | each request needs its own relevant carriers |
| Frame-chained I2V | immediate action/composition continuation | approved exact terminal frame, drift monitored against master |
| Native extension | temporal continuation from a real source clip | only when the exact operation exists and clip is bound |
| Native multishot | one job with documented shared context | shared context is not inherited by another job |
| Hybrid | anchor/insert/dialogue need different control | explicit handoff between operations |

A frame chain proceeds only from an accepted frame. Compare face, garment, product, room, light and texture to original masters, not merely to the last already-drifted frame. If drift accumulates, restart from a validated anchor or switch to independently conditioned coverage.

Relative phrases are not universally forbidden. “Preserve the source timing” is meaningful when a source clip is bound. “Same woman as before” is not meaningful when the new job receives neither her reference nor shared context. Fix the missing relationship rather than banning a word mechanically.

Each shot-to-shot handoff records accepted terminal state, exact carrier, next opening state, travel/axis, prop/hand state and any audio tail. The metadata alone is planning evidence; the next request must actually receive the carrier.


## 13. Human dialogue before model syntax

A line should do something: request, resist, conceal, reveal, test a relationship, trigger action, land a joke or make a decision. Ask what the speaker wants, what is unsaid, what both people already know and what pressure shapes this moment. Narrative dialogue is authored by screenplay-story-architect; standalone marketing/editorial copy and short VO wording by copy-voice, supported by humanizer; lyrics by audio-production-director. The compiler consumes accepted text and uses the checks below to identify a proposed repair, not to silently run a second writing pass.

Human-voice passes:

1. Remove exposition already visible or known to both characters.
2. Use breath-sized phrases and concrete spoken verbs.
3. Choose register from relationship and situation, not demographic stereotypes.
4. Give the line one playable intention or turn.
5. Leave a listener reaction or an afterthought.
6. Estimate speakability; measure only if an actual read is performed.

Avoid generic corporate openings, symmetry for its own sake, repeated empathy, complete feature catalogues in casual speech, redundant names, identical cadences, random fillers and emotion labels without action. Natural does not mean adding “um” or making every person swear.

Polish: use natural syntax, proper case/aspect/gender/address form and context-appropriate particles. Do not translate English sentence structure literally or stack diminutives as an authenticity trick. English: contractions and fragments when register permits, not forced slang or phonetic dialect caricature. Preserve the target language and diacritics inside an English technical prompt.

Approved copy is locked. If it is unspeakable in the allotted time, flag the conflict and offer a longer duration, split, VO, simpler action or a proposed shorter alternative outside the locked artifact. Do not silently “humanize” approved words.


## 14. Direct speech as visible performance

For every line establish speaker, exact words, language, on/off-camera ownership, timing estimate, intention, gaze, mouth visibility, gesture, listener behavior and acoustic perspective.

An acting beat can have a pre-line thought/breath, an impulse, delivery, one turn and an after-line response. Use only cues that materially affect the scene. “Tries to sound casual, then lowers her gaze on the last word” is playable; “extremely authentic, emotional, cinematic acting” is not.

Mouth accuracy requires a useful frame scale, visible lips/jaw/cheeks, manageable head/camera movement and no blocking hand/cup/hair at the speaking moment. If a hand action must cover the mouth, move the line before or after it, change framing or use VO. Do not demand perfect lip-sync through occlusion.

In short exchanges, specify turn order and listener reaction. Do not let both mouths own one line. Multi-speaker native audio, authorized voice binding and post lip-sync are different production routes; verify the chosen route rather than assuming all scene generators expose them.

For a presenter, use a script/performance packet: exact script, pronunciation notes, pace, pauses, emphasis, gaze, restrained gesture range, framing/background and disclosure. A presenter needs neither a dense cinematic environment paragraph nor imaginary API fields.


## 15. Sound design is causal and spatial

Separate dialogue, voiceover, diegetic effects, ambience, music, transition sound and mix perspective. Choose the lead layer for each beat. Dialogue, score, footsteps and mechanisms cannot all dominate simultaneously.

Tie effects to visible causes: step to contact, cap click to closure, pump sound to compression, impact to collision, cloth rustle to motion. A sound may precede a new visual as an intentional editorial bridge, but this is different from accidental cause/effect error.

Acoustic perspective follows location and distance. A close voice can be dry and intimate; an off-camera voice has a plausible position; a large room has a different decay from a bathroom or outdoor street. Do not request “studio dry” and “large reverberant hall” for the same source without a deliberate recording explanation.

Music direction can specify energy, instrumentation, rhythm and an original/authorized cue. Map available track sections to visual beats. Approximate generated synchronization is not frame-accurate editing. Do not claim knowledge of BPM, beats or timing without the actual track or supplied measured data.

Use native audio only when verified for the exact operation. Otherwise provide the visual prompt plus a separately labelled post-audio plan. Preserve actual voice authorization and do not imply a real person's endorsement or a genuine customer history through a synthetic performance. Use the shared [audio evidence and audiovisual handoff](../../audio-production-director/references/audio-evidence-and-av-handoff.md) for cue IDs, source/timebase mapping, VO/music/SFX priorities, captions, observed scope and sync readiness. Audio triage belongs to Audio Production Director; video and audiovisual alignment review stay here.


## 16. Human realism and wardrobe in motion

Fix structure before texture:

`identity/body geometry -> pose and balance -> intention/gaze -> primary action -> hand/foot contact -> expression -> material follow-through -> camera/light -> scale-appropriate detail`

For a close-up, stable eye/lid/lip structure, coherent gaze, regional skin variation and expression matter. For a medium presenter, face/body relation, breath, gesture and garment folds lead. For a full-body walk, silhouette, ground contact, step phase, drape and body proportion matter more than pores.

Do not invent unseen body details from a face-only image or beautify/de-age/reshape during a source-preserving pass. Mark angles not covered by an identity pack. Strong turning shots need appropriate profile information; a front portrait alone does not prove every angle.

Describe garments as constructed objects: silhouette, fit/ease, material class/weight, stiffness/stretch, panel/seam placement, collar/cuffs, closures, lining, print scale, hardware and attachment points. Their movement differs:

- structured wool: restrained delayed folds, stable shoulder/lapel geometry;
- poplin: crisp fold changes and light flutter;
- knit: joint stretch and soft recovery;
- silk/satin: fluid folds and directional moving highlights;
- denim: heavier inertia and local creases;
- leather: thickness, localized folds and limited flutter;
- technical shell: functional panels, crisp folds and coated response;
- straps/chains/fringe: secondary motion from fixed attachment points.

Hair remains rooted; masses and grouped strands follow inertia and wind. Fine detail that crawls should be reduced, not “enhanced” with more sharpness. Realism is an observable quality goal, never a promise of undetectable synthetic media.


## 17. Product films, ecommerce and claims

Choose what a shot proves: recognition, form, function, material, scale, fit, included items, use context or an approved offer. Product truth outranks spectacle.

Product ledger: SKU/variant, geometry, viewed sides, parts/count, label/logo, material/color, scale, moving mechanism, contents and allowed creative variation. Claims ledger: approved factual statement, subjective brand line, visual demonstration, testimonial, offer, disclaimer, unverified/prohibited claim. A photorealistic image of an outcome is not evidence that a product can cause it.

Useful shot families:

| Family | Construction | Protect |
|---|---|---|
| Hero/form reveal | one controlled camera or light change, stable end | shape, material, label, variant |
| Mechanism proof | approach-contact-force-response-result | real controls, count, scale, grip |
| Texture proof | one deformation/pour/flex in clear focus | sourced material/amount, no invented efficacy |
| Unboxing | orientation, actual parts and removal order | inventory and package truth |
| Fashion fit | silhouette, walk/turn, construction insert | garment SKU, body proportion, seams/closures |
| PDP set | separate clips answering buyer questions | each clip receives product truth |
| Paid social | hook -> proof -> payoff | early category, approved copy, usable close |

Category-specific risks remain important:

- beauty: amount, formula appearance, pump/dropper mechanics and contact; no invented clinical effect;
- electronics: ports/buttons/screens/cables and real UI; no fabricated performance/compatibility;
- food: serving amount, ingredients, viscosity/steam/foam and hygiene; no misleading ingredient props;
- jewelry/watches: stone/link count, clasp/dial, metal reflection and scale;
- furniture/home: proportion, joinery/modules, room geometry and human scale;
- footwear: side assignment, sole/laces, fit and grounded contact;
- kids/education: actual parts and safe use, no invented developmental/safety claim;
- regulated wellness: sourced label/copy, no disease outcome or fictional professional endorsement;
- automotive/industrial: actual model/trim/mechanism and operating context, no invented capability.

Keep exact video typography short and stable when native rendering is appropriate. If the production requires reliable captions, localization, exact UI or offers in an editor, plan a video clean plate with a held safe area and separate approved copy. This is a video postproduction option, not a replacement for a requested one-pass static poster or storyboard image with visible text.


## 18. UGC, short form and original hooks

Credibility comes from a coherent capture situation, not deliberate bad quality. Define why this person is speaking now, where the phone/camera is, what practical light exists, what product action is visible and which observation is honest. Distinguish a raw phone capture, polished creator content and brand-assisted UGC.

Do not give a synthetic spokesperson fabricated ownership history, medical results, review counts or the identity of a real customer. Scripted first person can be clearly fictional or authorized; it must not masquerade as observed testimony.

A short-form opening should be legible on mobile and have a reason to continue: a specific friction, visible contradiction, action already in progress, a question gap, proof first, a character dilemma or a purposeful pattern break. Use one lead mechanism, not seven competing tricks. A slower premium shot can still begin with a strong active visual.

Retention is controlled information release: promise/question -> visible progress -> complication/proof -> payoff/reaction -> close or loop. Not every second needs a cut. A reaction needs time to land. Paid content must reconnect entertainment to product and offer; organic content may lead more strongly with point of view.

Recompose horizontal/vertical versions from the shot's function. Verify actual platform safe zones when they matter; do not retain old exact pixel constants. Keep faces, mouths, hands and hero products at useful scale and out of UI collisions. Test muted readability and normal playback separately.

For trend-informed work, extract the retention mechanism, remove recognizable characters/catchphrases/audio/shot order, anchor an original premise in the user's objective, fit production constraints and label confidence. Historical popularity does not make the new idea current or predict success.

Variant testing changes one leading variable while keeping truth and relevant conditions constant. Supplied metrics can suggest a hypothesis: weak opening read, middle without progress, disconnected payoff or fatigued treatment. One small sample does not establish causality and no benchmark should be fabricated.


## 19. Sequences and terminal frames

Consume the approved sequence thesis: what changes, where the decisive proof/turn occurs and what each shot contributes. A beat need not become a separate shot. Remove a redundant shot only through the approved structural revision path, not secretly during prompt compression.

A production card should retain shot ID, function, duration, operation/context/shot construction, carrier manifest, opening state, action, camera side/scale/path/focus, sound, exact copy, terminal state, handoff and acceptance risks.

Choose an ending deliberately:

- hold: readable face/product/message;
- cut: a useful action endpoint;
- chain: a stable approved frame suitable as the next carrier;
- extension: ongoing motion that can continue;
- loop: compatible state, motion and audio phase;
- transition: an actual match/occlusion/direction/sound relationship.

Irreversible pouring, breaking, unboxing or one-way travel does not literally loop without reset. Use an explicit editorial concealment or redesign the action. Two unrelated endpoints should not be called physically connectable just because they are supplied as first and last images.

Risk-aware generation order is a later execution recommendation: references and keyframes, hardest truth/contact/dialogue shot, anchors, dependent coverage, inserts/transitions, close and repairs. It is not authorization to generate. Test difficult feasibility early rather than finishing decorative shots before discovering that the key mechanism cannot be shown.


## 20. I2V, first-last, extension and edit

**I2V:** the image owns opening appearance, composition, camera perspective, light and visible state. Describe intended temporal change. Do not redescribe a different identity, wardrobe or room unless transformation is explicitly the task.

**First-last:** compare identity, camera side, spatial path, pose/object state, light and available time. If incompatible, propose an intermediate frame, a deliberate cut or separate coverage. Do not promise perfect interpolation.

**Extension:** bind the actual clip; inspect its terminal pose/velocity, camera, object state, environment, light and audio tail. Continue from those facts, not from a text memory of the scene. Do not replay the source event by default.

**V2V:** distinguish surface treatment, world transformation and structural transformation. Larger change increases preservation risk. Source-motion retention depends on the actual tool, not simply a sentence saying “identical”.

**Local edit:** define source, time/region/property, one requested change, protected facts, allowed secondary changes, boundary behavior, audio policy and acceptance test. Changing an object's color may require changed reflections; adding a new light requires coherent new shadows. “Keep everything else” cannot freeze a physically necessary consequence.

**Replacement:** product/character reference must be available and authorized as appropriate. Match scale, pose/contact, occlusion, shadow/reflection, motion blur and perspective. Face-only substitution may fail body, neck, hair, hands, reflection and voice continuity.

**Motion transfer:** motion/camera source contributes cadence or path, not automatically identity, costume, room or audio. A target identity/wardrobe/carrier remains separate.

Maintain clean-source lineage. Each edit records accepted source/version, change, protected elements, observed drift and next decision. Compare repeated edits back to the clean master. Repair the operation or seam before adding adjectives.


## 21. Observable QA and bounded repair

Separate preflight from result inspection. Preflight can prove that a prompt is complete, the contract is coherent and assets are planned. It cannot prove that fingers, speech or labels will be correct in a future render.

Inspect only material actually available. A user report supports a qualified diagnosis. A thumbnail supports only that frame. Sampled frames may reveal geometry but cannot alone prove continuous motion or lip-sync. Report whether the full clip played, audio was heard, exact text was compared and which ranges remain uninspected.

Severity:

- cosmetic: small noncritical finish issue with truth intact;
- functional: readability, pacing, expression or shot purpose is weakened;
- truth-critical: wrong identity/SKU/copy/claim, impossible key contact, misleading testimony or broken required continuity.

A beautiful clip can fail because it falsifies the product. Do not average a truth-critical failure into a passing aesthetic score.

Keep visual/audio assessment separate from execution compliance. For a Studio-produced result, carry the applicable host/user tool, model, operation and authorization locks into QA. Confirmed prohibited execution blocks compliant delivery; missing provenance remains unverified. Appearance cannot establish which model was used. Do not apply a new-generation model restriction retroactively to every third-party reference or refuse useful criticism of an existing clip solely because its provenance is unknown.

Inspect opening, onset, peak/contact, recovery/end and both sides of every cut/edit seam. Record the first observable failure, not just the most dramatic collapse. Compare recurring identity/product/wardrobe to original masters.

| Observable failure | Structural question | First controlled repair |
|---|---|---|
| face changes on turn | is that angle covered; are refs conflicting? | restore master/angle, reduce turn or camera range |
| fingers fuse at grip | is interaction too small, complex or occluded? | enlarge contact, stabilize frame, simplify mechanism |
| feet slide | support/step phase/travel relation coherent? | restage weight transfer and ground contact |
| skin/fabric boils | too much detail for scale/motion? | reduce microdetail, stabilize focus, improve source |
| background bends | unsupported geometry/parallax? | restore location carrier, reduce arc/reveal |
| pump releases early | is contact before effect? | causal phases, remove competing motion |
| label mutates | scale/rotation/reflection or missing source? | source-bound frontal proof, simpler movement |
| camera jumps | incompatible moves or unclear path? | one motivated start-path-end |
| wrong speaker/words | ownership/time/mouth route clear? | restore exact line, isolate speaker, simplify frame |
| flat dialogue | line has no intent/subtext/reaction? | rewrite proposal before model syntax, respect copy lock |
| edit pop | boundaries incompatible or range too abrupt? | narrow target, integrate boundaries, compare clean source |
| shots do not match | carrier actually bound to both? | fix transport/handoff, not a longer adjective list |

Controlled loop:

1. Name observed issue, location/time and evidence level.
2. Separate likely cause from fact.
3. Preserve accepted elements.
4. Choose one principal repair variable and an observable pass condition.
5. Return a complete clean revised artifact for the chosen operation.
6. Inspect the supplied result against that condition.
7. After two controlled failures of the same symptom, reconsider the structural strategy. Do not add an endless list of bans or automatically spend on another model.

Possible outcomes: accept, polish, local edit, rerun, restructure, stronger source/carrier, split, different verified operation/model with approval, postproduction or stop with a real blocker. A changed strategy is a proposal until required execution authority exists.


## 22. Anti-slop quality gates for video

Anti-slop is not a phrase appended to a prompt. It is a set of decisions visible in the result.

**Specificity:** this action, object, place and human intention belong to this brief. If a generic model/product can be substituted without meaningful loss, revise the concept, not just its adjectives.

**Authorship:** camera and sound have a reason. Quiet restraint, lock-off and a held reaction are valid. Do not escalate every shot to orbit, neon, slow motion, particles and dramatic score.

**Causal integrity:** action, material and sound agree. Intentional surrealism has a consistent premise, not accidental incoherence presented as realism.

**Human voice/performance:** words are speakable, socially plausible, not generic ads disguised as dialogue. Pauses and gestures come from thought rather than a copied authenticity macro.

**Truth:** product, copy, identity, garment and reference roles survive visual polish. Apparent realism does not justify invented claims or customer experience.

**Temporal craft:** information is readable; no accidental frozen listener, expression snap, texture boil, meaningless montage or unearned cut.

For each failed gate choose a local, testable intervention. A preflight pass means the design is internally coherent. An accepted anti-slop outcome requires actual visual/audio review and, for subjective authorial fit, user review. Never promise that a prompt makes work “100% human-made” or guarantees virality.


## 23. Worked examples: six complete prompts and one shot-card handoff exercise

The following examples contain concrete illustrative briefs. They are not user-approved facts, source assets, live model settings or native API schemas. Adapt to real assets, requested duration and verified operation before calling one execution-ready.

### Example A. Fictional T2V observational shot

Intent: one human moment, one action and a motivated camera. No strict recurring identity is claimed.

```text
One continuous horizontal shot of a fictional adult ceramicist at a small workbench beside a north-facing window. A chipped unbranded stoneware cup sits within reach. She notices a faint glaze run near the handle, turns the cup a quarter turn with both hands, pauses, then gives a small private smile rather than looking at the camera. Keep the camera in a stable medium-close three-quarter view, with enough focus depth to see her fingers and the cup. Her linen sleeve folds after the wrist movement; the cup's window highlight moves with its rotation. The room stays still. End after the cup settles on the bench, with her hand resting beside it. No dialogue or visible lettering. Audio intent, if supported: quiet room tone, light ceramic contact and one soft exhale; otherwise keep this as a separate sound plan.
```

Acceptance: contact and release are ordered; expression follows noticing; no unmotivated environment motion. Adapter step: resolve actual duration and whether audio belongs in the generation prompt or separate post plan.

### Example B. Source-bound I2V product proof

Planned source: an approved starting image must show an unbranded pump bottle upright, a receiving palm under its nozzle and the operating finger just above the pump. If that image is absent or contradicts this state, this is a keyframe brief rather than an executable I2V prompt.

```text
Animate the supplied starting image as one continuous stable close shot. The operating index finger descends and makes contact with the pump before compressing it. Only after the pump moves, one small measured bead of the source gel enters the receiving palm. The finger releases, the pump returns, and both hands settle while the bottle remains upright. Maintain the source bottle, material, hand ownership, camera side, composition and room lighting. Keep the pump mechanism, finger contact and nozzle outlet in clear focus throughout. Do not add an insert or cut. End with the bottle and hands still enough to inspect the result. Audio intent, if supported: a restrained pump click at compression, faint sleeve movement and quiet room tone, without speech or music.
```

Acceptance: contact precedes dispensing; count/geometry remain stable; no implicit cut. This repairs the source K17 Example 25 contradiction by choosing a genuinely single-shot construction.

### Example C. Exact Polish dialogue and listener reaction

Illustrative locked lines: “Zostawiłeś puste?” and “Miałem kupić.” Two original fictional adults; no real person's identity or voice is implied. Confirm native dialogue route or supply a separate audio plan before execution.

```text
One continuous eye-level medium two-shot in a quiet ordinary kitchen. An adult woman stands on the left drying an unbranded cup. An adult man on the right has just placed an empty coffee jar on a shelf. Keep their positions, shared eyeline and both mouths visible. She notices the empty jar, stops the towel for a brief beat and looks at him. In natural Polish, with restrained disbelief, she says exactly: "Zostawiłeś puste?" He glances at the jar, takes a short guilty breath and replies exactly: "Miałem kupić." She holds his look for a moment, then resumes drying the cup without another line. Keep the camera locked, the gestures small and the expressions asymmetrical and familiar. Use soft room tone, cloth movement and a quiet cupboard contact; no music, captions or additional speech. Let the last reaction settle before the end.
```

Acceptance: exact words and diacritics, correct mouth ownership, pauses, no exaggerated sitcom acting. Speech duration here is a design estimate until actually read or rendered and timed. If the selected output duration is too short, change the duration/coverage, not the approved lines silently.

### Example D. Bounded source-video color edit

Source requirement: a real clip with an unbranded cobalt cup and accepted hand/camera motion. This is not a source-free regeneration prompt.

```text
In the supplied source clip, change only the cup's cobalt glaze to a deep forest green. Preserve the cup geometry, handmade surface variation, actor identity, hand contact, action timing, camera path, focus, room geometry and original audio. Allow the glaze highlights, reflections and nearby color spill to update only as physically required by the new color; preserve the underlying light direction and exposure. Keep the change stable throughout the visible cup's motion and across any occlusion. Do not change the sleeve, skin tone, workbench or surrounding objects. Finish with the source duration and terminal composition intact.
```

Acceptance: cup is consistently green; geometry/contact/timing remain; coherent secondary reflections. Compare entire relevant span and occlusion recovery. Do not claim frame-level masking or a temporal range field unless the surface has it.

### Example E. Frame-chained continuation

Required carrier: the exact approved final frame of the prior shot, showing a fictional adult holding one unbranded bottle in the right hand at chest height beside a table. A text reference to the previous shot is not sufficient.

```text
Start from the supplied approved frame. The right forearm lowers the upright bottle toward the clear tabletop in one controlled movement. The bottle base contacts the table before the fingers release. The hand withdraws to the right and rests outside the bottle's silhouette. Keep the source identity, wardrobe, bottle geometry, camera side, table position and light direction. Hold the camera steady; let the contact shadow tighten naturally as the base approaches the surface. End on the bottle standing unsupported with the hand clearly separated and the scene settled. No new objects, captions or speech. If audio is generated, place one restrained bottle contact sound at the visible contact and retain a quiet room bed.
```

Acceptance: source opening respected, hand release follows support, no axis flip. Input readiness can be checked before generation; actual continuity acceptance cannot.

### Example F. Fashion material, not universal flowy fabric

Required source: approved full-body start frame with the exact structured wool coat. This example does not invent a new garment from a brand name.

```text
Animate the supplied full-body frame in one continuous vertical fashion shot. The model shifts weight onto the left foot, takes two measured steps forward, stops and turns the left shoulder slightly toward camera. Use a restrained backward track that keeps the source camera side and full footwear visible, then settle as the model stops. Preserve the coat's shoulder line, lapels, belt attachment, buttons, seam placement, length and source color. The dense wool forms small delayed folds at the elbows and hem; it does not billow like chiffon. The belt tip follows the stop with a short, weighted lag. Keep foot contact, body proportions, identity, room geometry and light coherent. End in a readable three-quarter fit pose without additional gestures or a cut.
```

Acceptance: grounded steps, unchanged construction, material-specific lag and a usable fit hold. Do not demand macro skin texture in the full-body frame.

### Example G. Consuming an approved three-shot card set

Suppose an approved three-shot card set defines `S01 recognition`, `S02 mechanism`, `S03 payoff`, with exact durations, direction and copy. This module checks each card's input coverage and compiles one independent prompt per request or the single verified shared-context job specified by the plan. It does not merge the sequence into a continuous orbit merely to fit a favorite adapter.

Before compilation:

| Shot | Required evidence | Primary risk | Acceptance observable |
|---|---|---|---|
| S01 | approved hero product view | geometry/variant | correct silhouette and selected variant readable |
| S02 | mechanism angle and interaction/start state | contact causality | operation happens after correct contact, label/parts intact |
| S03 | accepted endpoint and exact approved copy plan | final state/continuity | product ends in intended readable hold, no unapproved words |

If S02 cannot prove the mechanism from available sources, return that blocker with two options: obtain the missing angle or propose a different truthful proof shot. Do not invent hidden mechanics or label the full pack execution-ready.

## 24. Revision hygiene and handoff format

Rebuild from current accepted state. Remove rejected concepts, old colors/lines, former diagnostics, absent aliases and references to prior chat. A small requested change still receives a complete usable revised prompt, unless the user explicitly requests only a delta for review.

Do not bury a critical blocker after an apparently final prompt. For a valid final artifact, put the usable prompt first and keep settings/explanation compact. For diagnosis, lead with the observed problem. JSON/YAML is optional unless the user or real interface requires it; never mix planning fields into an asserted API schema.

A video prompt handoff can use this planning record:

```yaml
prompt_id: "project-and-revision identifier"
shot_id: "approved upstream shot identifier"
narrative_video_prompt: "complete clean artifact, not a patch"
structured_video_prompt:
  status: "planning representation, not API schema"
  operation: "actual selected operation"
  context_transport: "actual carrier strategy"
  shot_construction: "single-shot or approved multishot plan"
input_assets:
  - alias: "approved semantic alias"
    role: "property authority and suppression"
    binding_status: "planned / available / bound / submitted"
duration: "approved duration or explicitly unresolved"
camera_and_motion: "approved path, action and terminal state"
continuity_locks: ["required property locks, with carrier coverage"]
avoid_rules: ["only task-relevant constraints, in supported syntax"]
research_and_execution_status:
  model_surface_operation: "verified selection or unresolved"
  capability_evidence: "record ID, date and limitations"
  unsupported_controls_removed: []
  authorization_status: "not granted by this planning document"
  qa_observables: ["concrete pass/fail tests"]
```

Use concrete values in real deliverables; this is a schema example only. A narrative-only user request does not require showing the whole internal packet. Mark untested host behavior, unverified model controls and uninspected media explicitly. A completed document is not a completed render.
