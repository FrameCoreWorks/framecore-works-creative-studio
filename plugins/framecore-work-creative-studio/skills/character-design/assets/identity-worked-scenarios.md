# Identity scenarios: original fictional examples

These examples are teaching cases, not client records, inspected images or pilot results. Alias names illustrate binding; they do not claim attached files exist.

## A. One front photo, requested right profile

Request: preserve a real person's exact likeness while turning them to a true right profile. Only a frontal image is described.

Keep required identity strict. Mark actual image inspection and profile geometry Unknown. Ask for the useful right-profile source if the missing shape changes the deliverable; do not request unrelated body views. A proposed profile can be labelled a candidate only if the user accepts that exploratory scope. Never promote that candidate into verified anatomy. Continue any independent composition or background planning.

The output handoff states the face source role, the missing view, what must remain fixed and that exact-profile execution is unresolved. It does not claim that adding more identity adjectives supplies the absent view.

## B. Three people in one image

Request: put three supplied characters together, preserving each face and outfit.

Assign one stable character ID to each source set. Separate face, costume and pose authority. Describe each person's own role and relative position so a source's glasses, hair or suit does not migrate to another person. Use subject names or neutral character IDs; positional language alone becomes ambiguous when the camera changes. Keep the group composition source separate from identity sources.

If the chosen target cannot bind all necessary inputs, preserve the requirement and resolve that capacity conflict. Do not assert that a contact sheet of three faces is equivalent to three native identity references. The final group image needs per-character inspection for identity, costume and anatomy; a correct centre character does not validate the others.

## C. Realism correction without redesign

Request: remove waxy skin from an existing accepted portrait while keeping the person and image composition.

Retain the existing image as the edit base and the accepted identity references for likeness. Limit change to the unnatural surface rendering and its local light response. Preserve face shape, eye size, expression, pose, clothing, crop and background. Do not add age, scars, visible pores at every scale or new makeup as an authenticity shortcut.

If no output image is accessible, prepare the scoped repair instruction based on the reported issue and label the inspection gap. A later result is a new candidate. The accepted source remains selected until the user accepts that exact replacement within the requested workflow.
